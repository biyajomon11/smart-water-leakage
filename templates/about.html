MCA Final Year IoT Project

Smart Water Leakage Detection and Real-Time Monitoring System Using ESP32

An industrial-grade Internet of Things (IoT) solution engineered to provide zero-latency water leakage detection, local hardware alarm failover, and cloud/edge real-time telemetry analytics using an ESP32 microcontroller, Flask backend, PostgreSQL database, and Docker containerization.

System Architecture & Data Pipeline

From edge surface sensing to containerized database storage and dashboard visualization

1

Edge Sensing

Water surface sensor detects moisture conductance on GPIO 34.

GPIO 34 • ADC1
2

Instant Local Alarm

Autonomous edge failover: Buzzer (GPIO 25) & Red LED (GPIO 27) trigger in <10ms.

Offline Protected
3

REST Telemetry

ESP32 sends HTTP POST JSON payload to Flask backend with Wi-Fi RSSI.

HTTP POST • JSON
4

PostgreSQL & Web UI

Persistent time-series storage, real-time Chart.js graph, and instant alerts.

Docker • SQL DB

Software & Frameworks

  • Frontend: HTML5, CSS3, Tailwind CSS, Vanilla JavaScript, Chart.js, Lucide Icons
  • Backend: Python 3.11, Flask REST API, Gunicorn WSGI, Flask-CORS
  • Database: PostgreSQL 15 (with relational schema, indexes & SQLite fallback)
  • Containerization: Dockerfile & Docker Compose with persistent storage volumes

Key Features & Safety Design

  • Autonomous Hardware Operation: Physical alarm works even if Wi-Fi or server is offline.
  • Zero False-Alarm Logic: Buzzer sounds ONLY when water is detected, completely silent when dry.
  • Heartbeat Telemetry: Automatic detection of offline ESP32 units within 15 seconds.
  • Audit & Compliance: Incident resolution duration tracked and exportable as CSV.
